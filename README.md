# Workforce Performance Dashboard

##  Overview
This project analyzes workforce productivity, SLA compliance, and workload distribution using Tableau.

##  Live Dashboard
https://prod-in-a.online.tableau.com/#/site/ckdeeshna-9e72970c58/views/WORKFORCEPERFORMANCEDASHBOARD/Dashboard1

##  Key Insights
- High workload reduces SLA performance  
- Balanced workload improves productivity  
- SLA drops during peak lead volume  

##  Tools Used
- Tableau (Dashboarding)
- SQL (Data Processing)
- Data Analysis

##  Objective
To monitor team performance and identify factors affecting SLA and productivity.
